## About

I'm an ECE student working at the layer where silicon meets the physical world — designing digital hardware and writing firmware that turns sensors into connected systems.

My interests span **RTL design**, **microcontroller-based embedded systems**, and **IoT architectures**. I care about clean, documented code and understanding what actually happens beneath the abstraction.

## Areas of Focus

| Area | What I work with |
| --- | --- |
| **VLSI / Digital Design** | Verilog, SystemVerilog, combinational & sequential logic, FSMs, testbenches, synthesis and timing fundamentals |
| **Embedded Systems** | ESP32, Arduino, ARM Cortex-M, C/C++ firmware, UART / I2C / SPI, sensor interfacing |
| **IoT** | Wi-Fi connectivity, MQTT, edge-to-cloud data flow, low-power node design |
